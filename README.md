# 🛒 Lista de Compras en la Nube

## 📚 AA8 - Aprendizaje Autónomo

**Fecha de Entrega:** 2026-07-02

---

## 📝 Descripción

Aplicación web para **gestionar tu lista de compras** desde cualquier lugar. Permite:

- ✅ Ver todos los productos de tu lista
- ✅ Agregar nuevos productos fácilmente
- ✅ Eliminar productos que ya compraste
- ✅ Ver el total de productos en tu lista

---

## 🛠️ Tecnologías

**Frontend:** HTML5, CSS3, JavaScript
**Backend:** Node.js, Express.js
**Nube:** Render.com
